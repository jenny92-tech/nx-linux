# 准备与安装

1. 将自己持有的匹配本体、更新包和 Key 放入私人输入目录。使用同一游戏版本对应的模块、资源和 runtime；当前源码处理 90447、94012。
2. 在电脑运行 `bash dm/linux/prepare-classic.sh --device rk3566-2gb --input /自己的/input --out /自己的/prepared`。默认经典精简资源；`--check` 只检查输入和依赖，断点继续使用 `--resume`。附加资源仅在显式 `--resources full` 时保留。
3. 使用匹配的 Release 软件包安装准备结果，明确 runtime、游戏、控制器和原 profile 的路径。首次安装写默认设置，升级沿用玩家角色、身份和设置；详见[机型路径](devices/README.md)。

准备器依赖自己的 NSP、Key，以及已安装的解包、.NET/着色器翻译、SPIR-V、压缩工具。具体缺项由 `--check` 报告；本工具不下载游戏或 Key。依赖安装应在输入和来源确认后单独进行。

`--out` 是独立生成目录，不指向原输入。校验不匹配时保留输入，修正后继续；不要用跳过校验替代正确的配套版本。

当前默认适配目标为 2 GB 经典平面菜单；4 GiB 实机上的验证不能替代真实 2 GiB 或 1 GiB 设备验证。Rocknix 等不同驱动/固件还需单独检查图形与输入。

公开软件包只含许可允许的软件/源码。准备后的游戏模块、着色器、资源及玩家档案始终保留在私人环境。
